# Contributing to HACYBERGLOBALTECH Website

Thank you for your interest in contributing to the HACYBERGLOBALTECH website!

## Guidelines

### Code Standards
- Use semantic HTML5
- Write clean, maintainable CSS and JavaScript
- Ensure accessibility compliance (WCAG 2.1)
- Maintain responsive design for all devices
- Test dark/light theme compatibility

### Before You Start
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Make your changes following the style guide
4. Test thoroughly on multiple browsers and devices
5. Commit with clear messages: `git commit -m "Add feature description"`

### Pull Request Process
1. Update README.md with any new features or changes
2. Ensure all links are working correctly
3. Test the website locally
4. Provide a clear description of changes
5. Reference any related issues

### Reporting Issues
Please report bugs with:
- Clear description of the issue
- Steps to reproduce
- Expected vs. actual behavior
- Browser/device information
- Screenshots if applicable

### Design Principles
- Mobile-first approach
- Performance optimization
- Security best practices
- User experience focused
- Accessibility compliant

### File Organization
```
assets/
├── css/          # Stylesheets
├── js/           # JavaScript files
├── images/       # Image assets
└── fonts/        # Font files

pages/
├── services.html
├── about.html
└── contact.html
```

### Deployment Notes
- All changes to `main` branch trigger automatic Cloudflare deployment
- Test locally before pushing to main
- Ensure no sensitive data is committed
- Update version history in README.md
- Check Cloudflare Analytics after deployment
